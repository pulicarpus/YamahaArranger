This is a community document compiled from private experiments, with an explicit non-Yamaha disclaimer (p.4). It supports a precise documentary hypothesis, without a verified execution oracle. The open-issues section still asks about practical use of this feature. No vendor binary specification or labeled input-root/output fixture was found in the inspected material.
