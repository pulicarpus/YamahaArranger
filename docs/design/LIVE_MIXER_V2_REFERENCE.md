## LIVE CONTROL V2 (user-approved visual)

Use the reference image `LIVE_CONTROL_V2.png` from the companion `YamahaArranger_Visual_Design_V2.zip` package shared in the ChatGPT project conversation (14 October 2026).

- Yamaha PSR-SX / Genos / Tyros-inspired dark blue, tactile, high-contrast touchscreen control panel for Redmi Pad landscape.
- Top strip: current STYLE, chord, tempo, beat; transport START/STOP, INTRO I–III, ENDING I–III, MAIN A–D, FILL A–D, ACMP, voice part toggles, RELEASE.
- Four RIGHT1/RIGHT2/RIGHT3/LEFT voice strips.
- Eight REGISTRATION MEMORY slots, bank navigation, MEMORY and MENU.
- **Add a visible MIXER navigation button** beside MEMORY/MENU; allow return to LIVE without stopping the style.
- The illustration contains a SUSTAIN button, but the implemented YamahaArranger contract uses RELEASE ON/OFF and knob; do **not** reintroduce SUSTAIN or assume SYNC START/BREAK/TAP are implemented. Unsupported features must be visibly disabled until verified.
- Treat the image as a **visual goal**, not as evidence of implemented APIs or preset availability.

## MIXER V2 (user-approved visual)

Use the reference image `MIXER_V2.png` from the same package.

- Full-screen landscape channel strips with realistic vertical faders, strong color differentiation and readable value labels.
- RIGHT1, RIGHT2, RIGHT3, LEFT, used STYLE channels and MASTER; do not invent unused active channels.
- MUTE, SOLO, channel volume, PAN; advanced settings such as EQ/effects only when backed by actual working APIs.
- Channel filters, mixer navigation and return to LIVE/ARRANGER.
- Avoid decorative animated level meters unless actual signal measurements are available; no fake audio levels.

## Functional safety requirements (higher priority than styling)

1. Preserve the playable style checkpoint and current LIVE/REG Phase 0–4 guards.
2. The user's Yamaha PSR-E343 is connected to Android **by USB MIDI only**, Local Control OFF. The audible E343 sound is generated by its own tone engine from YamahaArranger **MIDI OUT**; SF2 audio is not sent over USB MIDI.
3. REG recall must support independent external Yamaha MIDI voice identity (MSB, LSB, Program) and internal BASSMIDI/SF2 identity; do not mirror SF2 bank/program to E343.
4. Never auto-send Bank Select/Program Change on MIDI OUT connect, reconnect or enable. Explicit voice selection or user-initiated REG recall may send validated external MIDI program changes.
5. Preserve RIGHT part note ownership, isolated OFF, RELEASE effective-value semantics, and continuous style playback during navigation or REG recall.
6. Do not introduce speculative features, engine edits, new MIDI routing or design-only changes into the active Codex Phase 4 build.
